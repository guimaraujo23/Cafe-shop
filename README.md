# ☕ Cafe Shop

Um site moderno e responsivo para uma cafeteria, desenvolvido com HTML, CSS e JavaScript.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura e marcação semântica do site.
- **CSS3**: Estilização e layout responsivo.
- **JavaScript**: Interatividade.
- **Font Awesome**: Biblioteca para ícones vetoriais.
- **SwiperJS**: Biblioteca para carrosséis e sliders interativos.

## 📌 Funcionalidades

- [x] Cabeçalho com navegação e logo.
- [x] Sliders interativos para destaques e produtos.
- [x] Design totalmente responsivo (adaptável para telemóveis e computadores).
